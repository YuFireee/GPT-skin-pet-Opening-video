# 自动生成角色图的提示词

这些提示词由具有图片生成能力的安装会话执行。图片只存本机，仓库不包含示例角色图。使用用户上传的主题参考图；每个后续动作都引用已生成的常态图，以保持同一角色。生成后实际查看图片，确认画布对齐；若图片工具不支持真实透明背景，应明确说明，不能把棋盘格背景当成透明。

## 常态 idle.png

根据用户上传的主题图制作同一角色的Q版半身桌宠立绘。保留可辨认的发色、发饰、瞳色和服装设计，精细干净线稿、柔和上色，神态自然。正面略侧，双手自然放下，半身构图，完整保留两侧头发和发饰。1024×1024正方形画布，真实透明背景。角色居中，顶部和左右留出8%安全边距，半身底线在画布高度92%，角色约占画布高度82%。不要文字、边框、额度圆环、地面、背景和水印。后续所有姿态沿用这张图的比例、朝向、脸型和底线。

## 执行 executing.png

编辑常态基准图为正在认真思考的姿势：一只手自然抬起，手指轻托下巴，手腕与袖口、前臂和上臂衔接自然，另一只手自然放置；目光略向一侧，带可爱的思考感。人物身份、脸型、头部位置、衣服、发饰、画风和构图与常态相同。不能把下颌线画在手的可动部分，不要拉长手臂，不要额外手指，不能裁切。输出相同画布大小和真实透明PNG。手已经到位，运行时基础动画只做轻微整体倾动，不模拟复杂关节动作。

## 待确认 confirmation.png

编辑常态基准图：角色双手分别举在自己左右脸颊的外侧，食指与中指形成可爱的V字剪刀手，两个V字向内倾斜、指尖朝向自己的脸颊，手臂连接自然，双手不要挡眼睛、鼻子、嘴巴和中央下巴。目光朝向使用者，轻微歪头，像在等待回应。保持人物身份、发色服装、脸型比例、画布位置、朝向、底线及线稿风格完全一致，真实透明背景，相同画布大小，无文字或水印。

## 三张闭眼图 *-blink.png

分别编辑刚生成的 idle.png、executing.png、confirmation.png。只把两只眼睛改成自然眨眼闭合的弧线；眼睛之外的全部像素、姿态、头部、下巴、头发、发饰、手指、服装、画布和透明边缘保持原样。不要改变表情、嘴型或人物大小。输出与输入相同尺寸、相同人物位置的透明PNG，依次命名 idle-blink.png、executing-blink.png、confirmation-blink.png。若眼睛之外的位置发生明显变化，应重新编辑后再导入，避免眨眼时画面跳动。

## 可选主题背景 theme.png

根据用户的参考图生成适用于桌面阅读界面的横向主题背景，沿用角色与画风，角色靠左，右半区域保持低对比、适合叠放文字与输入框。光线柔和，色调统一，不画任何聊天界面、文字、Logo、按钮或水印。输出工具实际支持的最高合适分辨率并如实报告，不用插值放大冒充原生4K。若原主题图已经合适，直接使用用户原图即可，无需重复生成。
