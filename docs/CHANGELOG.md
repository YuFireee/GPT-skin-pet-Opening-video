# 更新记录

## 0.9.6 · 2026-10-28

- 使用 Windows 原生端口表检查连接，保留进程、端口及回环地址校验，减少启动等待。
- 安装时预先编译桌宠组件，减少每次打开时的重复编译；角色静态图按动画所需尺寸解码。
- 保留隐藏后释放动画缓存、连接失败停止检查及有限次数的端口恢复。
- 补充 IPv4/IPv6 身份核对、预编译动画与资源释放检查。性能数据及测量范围见 RESOURCE_CHECK.md。

## 0.9.5 · 2026-10-27

- 跟随的旧窗口隐藏后，可切换到另一个可见主窗口；排除最小化和其他虚拟桌面的隐藏窗口。
- 修复桌宠显示后仍报告“等待中”的状态问题；未变化时不重复写入状态文件。
- 控制窗口区分“桌宠已显示”和“等待可见主窗口”。

## 0.9.4 · 2026-10-27

- 异常退出后，如原端口的占用进程已不存在，换用空闲本地端口，仅重试一次。
- 记录新端口供下次启动使用；不接管或结束其他程序。
- 启动失败提示显示具体原因。

## 0.9.3 · 2026-10-26

- 显式启动后允许有限的窗口创建与页面加载时间。
- 不再仅因主窗口被遮挡而误报启动失败。

## 0.9.2 · 2026-10-25

- 提供由仓库链接、主题参考图和用户影片开始的安装提示词、角色图片提示词及素材制作工具。
- 自动整理117个本地素材槽位；用户影片默认使用通用末帧花瓣层。
- 原创代码与文档采用 MIT 许可，保留第三方许可；媒体不随源码分发。

## 0.9.1 / 0.9.0

- 原生轻量控制窗口、托盘菜单与静态主题预览。
- 移除旧蓝白裙桌宠，保留一个可替换的角色槽位。
