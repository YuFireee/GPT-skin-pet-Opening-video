# 视频演示与发布文案

## 简短口播

这是一个运行在 Windows 上的主题和额度桌宠工具。界面背景、三个对话状态、额度圆环、启动影片和托盘控制都在本地运行。源码放在视频简介的 GitHub 仓库里，不附带演示角色图片或启动影片。

想制作自己的版本，可以把仓库链接和安装提示词发给支持本地操作及图片生成的 GPT/Codex 桌面会话，再上传一张主题参考图和自己的启动影片。它会根据参考图制作角色状态图，并用工具整理运行素材、转码和编译。基础循环支持眨眼、轻微呼吸和思考倾动，效果取决于生成图片。没有图片生成能力时，也可以自行准备状态图。

首次使用需要自己的账号登录。没有账号、聊天记录或原作者素材被打包到仓库里。请使用自己有权使用的图片和影片。

## 简介模板

源码：替换为你发布后真正的GitHub仓库链接。

安装：仓库 README →「让 GPT 帮你安装」→复制完整提示词，和仓库链接、主题图、启动影片一起发送。

系统：Windows 10/11 x64；需要能操作本地文件的桌面会话和可用绘图功能。普通聊天窗口不能保证自动安装。依赖包括 Node.js 22+、Windows .NET Framework、FFmpeg/FFprobe。

演示图和影片不随源码提供；AI制作不等于取得参考角色或影片的公开分发授权。源码MIT许可及第三方许可见仓库，媒体权利单独处理。

## 建议展示顺序

1. 启动影片、末帧等待及就绪后跳过。
2. 控制窗口静态预览、托盘开关桌宠。
3. 常态、执行、待确认三种角色姿态及额度/台词点击。
4. 展示仓库不含图片和账号资料；展示用户自备主题图与影片的安装流程。

录屏前隐藏账号名称、额度详情、聊天内容、本机路径和其他隐私。演示中不要把模拟数据称为真实额度，也不要把未实际运行的自动安装称为已验证。
