# 验证范围

当前公开版：**0.9.6**。整理日期：2026-10-28。本轮从待上传 ZIP 解压干净副本，确认原生编译、53个 JavaScript 文件语法、52个 Windows PowerShell 5.1 脚本解析、素材生成/导入和隔离控制窗口检查通过。以下区分已经执行的检查和仍需要实际环境验证的内容。

## 已执行的检查

- 公开源码：JavaScript 语法、相对导入、JSON、素材槽位、安装文件清单及敏感信息模式检查。
- Windows 原生编译：控制窗口、启动窗口、原生端口检查库和预编译桌宠组件。
- 素材流程：用测试图形和短影片生成117个素材文件，导入并核对哈希，再编译运行副本；覆盖有声/无声影片、H.264/AAC 转换、真正末帧提取、不放大低分辨率影片、拒绝覆盖已有素材及拒绝不透明角色图。
- 控制窗口：30次开关、静态预览加载与释放、素材缺失提示、托盘唤起、关闭后停止轮询及随后台退出。
- 桌宠：隐藏旧窗口后的目标替换、扫描节流、显示状态恢复、圆环和角色点击、三种动画切换，以及预编译组件下的12次显隐与缓存释放。
- 连接与启动：专用进程校验、窗口创建宽限、端口异常恢复仅重试一次、其他程序占用端口时拒绝接管，以及失败后停止自动检查。
- 原生端口表：使用测试进程自己的 IPv4/IPv6 回环监听器核对 PID、地址和端口，与 Windows 查询结果比较。
- 源码 ZIP：解压完整性、版本一致性，以及媒体、编译产物、账号目录和测试输出的排除。

大多数检查使用自有窗口、模拟接口或测试素材，不会为了测试重复启动真实桌面应用或查询账户。检查通过不代表任意主题图的AI绘制品质都合格。

## 性能测量的范围

本机一次对照测得：完整连接检查约2871ms→1309ms；桌宠 CheckOnly 初始化约1847ms→1258ms。后者不含进程启动、主窗口就绪等待、动画帧解码及额度网络查询，不是完整启动时长。短时缓存释放检查也不能替代多小时运行、显卡驱动和多屏环境测试。

详细记录见 [资源检查](RESOURCE_CHECK.md)；机器可读摘要见 [verification-summary.json](verification-summary.json)；更早的观测数据已归档到 [历史摘要](history/verification-summary-legacy.json)，不能当作当前占用。

## 没有作出的保证

未声明当前版本的 `npm test` 在所有环境整套通过。部分旧版本的 Esc 实键测试曾因 Windows 焦点限制中止，不能算成功；相关历史记录保留在 [2026-10-22记录](history/VERIFICATION_2026-10-22.md)。本次源码整理不会把旧版本或模拟测试结果当成当前真实按键验收。

完整窗口测试需要可交互 Windows 桌面、测试窗口能获得焦点、本地素材和相应开发依赖。GitHub Actions 只执行其工作流中列出的源码、编译与隔离检查，不代替真实桌面验收。桌面应用升级后，选择器和窗口识别仍可能需要适配。

## 自行检查

普通使用不需要运行测试。开发者可以按仓库 README 中的“开发者检查与导出”执行。

- `npm run audit:source`：检查公开源码，不要求个人素材或浏览器。
- `npm run audit:runtime`：核对导入后的本机素材，需要先执行准备程序。
- `npm test`：完整本机测试；需要测试依赖、可用浏览器、外部素材、完整 FFmpeg/FFprobe 和可交互桌面。

检查产物保存在被忽略的 `reports` 中。敏感信息模式扫描存在漏检可能，公开发布前仍应检查实际 ZIP 内容。
