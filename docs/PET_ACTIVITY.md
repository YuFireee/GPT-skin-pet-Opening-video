# 桌宠功能与边界

当前公开版：**0.9.6**。这里只描述当前保留的功能；旧版本的尝试和已取消功能见 [历史开发记录](history/PET_ACTIVITY_LEGACY.md)。

## 角色与点击操作

当前只有一个可替换的角色槽位。头顶显示两个剩余额度圆环：左侧为5小时，右侧为每周。点击圆环打开额度面板，点击角色显示或切换台词。气泡显示时隐藏圆环，收起后恢复。未取得有效额度时显示未知，不用其他时间窗口的数值代替。

角色保留常态、正在执行、待确认三种状态。状态来源是可识别的本地对话记录；过旧或无法识别的记录回退为常态，不代表能识别每一种工具或会话场景。图片制作与状态识别是两件事：公开版根据用户提供的图像生成素材，具体动作效果见 [图片提示词](IMAGE_PROMPTS.md) 和 [安装说明](INSTALL_WITH_AI.md)。

默认运行素材不随源码提供。新用户生成的基础循环包含眨眼和轻微整体呼吸/倾动，不能直接复现原演示素材的精细分层头发、头部或手部动画。

## 额度与用量统计

额度面板展示账号返回的有效额度窗口和重置时间；它与本地 Token 统计分别计算。日报和模型/时段摘要依据本机日志，采用近7个本机自然日及约5小时的轻量窗口。首次只有限量读取，历史数据可能不完整，统计结果不是完整账单。

额度提醒与可选的第三方重置公告分别处理。第三方计划公告不等于账号额度已恢复；实际恢复提醒仍以账号数据为依据。查询失败后不持续反复调用不可用的默认应用。

## 显示和控制

控制窗口和托盘可以开启或关闭桌宠。角色右键菜单提供位置、缩放、跟随/桌面显示、声音、动画、台词和快捷按钮等设置。跟随模式下，主窗口隐藏或最小化时桌宠会等待；出现可用窗口后再恢复。窗口隐藏时释放动画帧，异常时可回退为静态图。

当前未启用视频全屏自动让位，取消了旧任务列表和任务状态面板，也不提供单独的模型聊天入口。保留在源码中的上游更新辅助文件不代表应用内自动更新已启用。
