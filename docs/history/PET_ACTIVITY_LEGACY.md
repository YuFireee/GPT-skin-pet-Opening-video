# 0.8.29 柔光格裙常态动画

保持原姿势、头部角度和身体不动，只做局部发梢/发饰轻微摆动和眨眼。27帧512×512透明PNG，循环4970ms；发梢最大位移约3.8px/512，相当默认208px角色约1.5px。闭眼局部由内置image_gen编辑，其他区域使用原图。像素核验覆盖固定区域，素材仅本地，不包含于公开代码。

C# DispatcherTimer按帧时长驱动Image.Source，无每帧PowerShell回调；仅当前柔光格裙版启用。隐藏/最小化/关闭开关后停表、清空解码帧、恢复静态贴图，显示时按需重载。最多64帧、单帧512px、解码预算48MiB、文件与帧时长检查；异常回退静态且不自动重试。设置→显示与声音→常态动画可关闭。原图用于透明命中检测并继续保留。

检查覆盖透明GIF/APNG解码、固定像素、循环时长，原生动画推进、隐藏释放、关闭开关及12次显隐循环（回收后托管8.5→8.5MB）。桌宠完整运行检查另见本地报告；不代表多小时GPU/驱动兼容保证。待确认与正在执行角色动画尚未制作，此次未恢复任务列表或对话状态识别。

# 0.8.28 资源测试与额度刷新内存增长修复

实测旧桌宠约11分钟从188.9MB涨至621.4MB，托管内存从41.5MB至330.1MB；超限保护关闭进程。已在隔离环境复现，并非仅凭短时间CPU低就认定正常。

根因：Windows PowerShell 5.1对保留的PSCustomObject反复使用位置式Select-Object，会累积Selected.*类型标记和缓存。Get-QuotaRows每次心跳复用同一status.windows并执行Select-Object -First。旧路径1500次刷新后类型名总长度78056、托管内存136.6MB；改用直接遍历后4000次长度始终56、托管内存约14.8MB、私有内存约127MB。提醒事件末尾选择同样改为索引，额度环复用DoubleCollection减少分配；未在生产代码添加强制GC。

相关上游讨论：https://github.com/PowerShell/PowerShell/issues/11441 。本项目根因结论以自身修复前后复现结果为依据，不将上游新版本的修复视为本机5.1已修复。

180秒隔离持续运行通过：私有内存193.5→191.7MB（峰值213.3MB），句柄1865→1799；没有生产代码强制GC或定期重启。

新增check-quota-memory.ps1针对累计元数据与保留内存的回归，check-pet-resources支持62..600秒隔离运行，默认180秒并清理旧测试收据。之前一分钟、空额度的测试不足以捕获该问题；现在以非空额度记录4000次刷新补足。

真实后台观测到效果层/花瓣/效果动画均为0，60次主题切换后DOM与监听器数量未增长。后台CPU阶段的自有测试窗口未能持续获得前台，不能声称已完成严格受控的实际应用前后台CPU对照。长期多小时运行、驱动GPU显存和其他应用卡顿因果仍未排除。

# 0.8.26 全屏与截屏显隐修复

确认全屏后通过可见性条件真正隐藏桌宠，不再只改变Z序。退出后走原显示逻辑恢复置顶偏好。浏览器全屏几何允许保留最大化标志的窗口，普通最大化仍不覆盖完整显示器边界。

网页退出全屏控件接受Text/Custom等可访问节点及HelpText；同时识别包含Esc的网页退出全屏提示，排除F11提示。扫描预算仍650ms/父进程1800ms及128MB上限；节点限制384、深度24。确认后在同一浏览器完整覆盖屏幕期间维持隐藏，避免播放器控件自动消失造成重复显隐。嵌套F11与视频全屏在同一窗口内切换时仍有状态滞留风险，须退出窗口全屏才清除确认。

ScreenClippingHost/SnippingTool/Snipaste/QQScreenshot/ShareX等已列出截屏进程临时置前时保持先前显隐状态，不将其判为全屏播放器；未知截屏工具尚需补充。presence.json增加fullscreenReason用于本地诊断。

隔离检查覆盖非按钮控件、Esc通知、F11工具栏排除、截屏进程排除及实际可见性条件。未对用户B站页面取得有效全屏验证，不能以隔离检查替代真实网站验收。

# 0.8.25 选定的四项功能

后续范围仅包含以下四项；其余待办取消。

- 全屏让位：原生应用仍用同屏窗口几何检测；浏览器需确认网页 Document 内可访问的“退出全屏”按钮，窗口工具栏的 F11 退出按钮不算。单次辅助进程最多192节点/12层，扫描预算650ms；父进程1800ms或128MB终止，异常退避60秒。不在桌宠进程内执行 UIA。隐藏控件、非标准播放器和未列出的浏览器可能无法确认，此时保留桌宠，不宣称完整兼容。
- 卡片过渡：从胶囊位置与大小展开，联动窗口宽高、位置、圆角及透明度；240ms展开、180ms收回。关闭清理动画；无常驻动画计时器。角色图片不缩放。
- 第三方公告：Codex Resets 公开 API，来源链接 https://codex-resets.com/api/docs 。仅前台且开关开启时读取，30分钟持久缓存、ETag、5秒超时、64KiB上限、429退避。计划公告不会因时间已过而被当成已执行；与账户真实恢复提醒独立。额度卡片查看摘要，设置面板查看详情；失败保留缓存并标注过期。
- 统一设置：右键“桌宠设置与连接诊断”或额度卡片齿轮进入。显示、声音、配色、提醒、公告、只读诊断及最多三个快捷按钮。快捷入口可选本地功能或HTTPS网站；保存不执行，点击失败不重试，拒绝脚本/文件协议。沿用同一个 settings.json。
- 修复重启强制覆盖配色设置；隐藏桌宠时同步关闭所属卡片并终止检测助手。补齐安装所需运行时文件清单。

隔离验证覆盖真实WPF开关/过渡/引用清理、快捷地址校验、保存不启动网站、UIA视频按钮与F11工具栏排除、公告缓存/重启/失败/限流及旧额度、日报回归。未操作用户播放器或启动实际GPT；真实浏览器网站、多屏DPI和长期运行需继续观察。

# 0.8.24 额度提醒

默认开启，右键“额度提醒”可关闭，低额度阈值可选10%/20%/30%（默认20%）。同一低额度阶段提醒一次，余额回升至阈值以上5个百分点后才重新进入下一轮。近15分钟重置提示为预计，不等同账户已经恢复。

实际恢复须新鲜有效查询确认：同账户同额度窗，旧重置时间已过，新重置时间进入未来且余额至少回升1个百分点。单纯时间到、首次读取、账号切换、错误、超过180秒数据和重复观察时间不触发恢复通知。

状态与最近12条事件保存在用户本地quota-alerts.json；UI在现有刷新路径检查文件时间，只在变化时解析。提示8秒自动收起，可点击展开卡片，无新计时器或额外查询。全屏期间暂缓，超过5分钟的旧提示丢弃；不抢焦点、不强制置顶。已显示标记保存在本地，重启不重复。

隔离检查覆盖阈值、预计重置、确认恢复、重复/重启去重、失效/账号变更、全屏暂缓和关闭设置。实际账户跨重置时间的长期验证尚未完成。

# 0.8.24 全屏让位

默认开启，右键设置的位置/显示选项中可切换“全屏时自动让位”。检测桌宠同屏的前台窗口是否完整覆盖屏幕边界，排除普通最大化、最小化、桌面/任务栏、自身窗口和其他屏幕窗口。只调用Win32，不扫描浏览器DOM或UIA，不创建额外进程/计时器；检查最小间隔500ms，使用已有约1秒Tick并双次确认抑制闪烁。

进入全屏时关闭额度/日报卡片、收起旧气泡、临时取消置顶并移到底部。退出后恢复原置顶偏好，不改变保存的设置，不自动重开卡片。可在presence.json查看fullscreenYielded状态。

这属于窗口级全屏识别，不识别具体播放内容；浏览器F11也可能触发。部分无边框游戏、特殊播放器、独占全屏及多屏混合DPI尚未逐一验证。隔离测试覆盖几何、普通最大化、自身/异屏排除、负坐标、进入退出防抖、限频、卡片收回和设置保留；本轮未控制用户播放器或启动实际GPT。

# 桌宠任务与 Token 第一版

参考功能来源：https://github.com/Wunsch2048/codex-bailong-desktop-pet

采用独立实现，未复制该仓库源码和角色素材；对方未提供统一开源代码许可证。

右键桌宠 → 任务与 Token 统计。已有额度查询与两套角色保留，不添加角色动画。

- 读取本机 CODEX_HOME（默认 ~/.codex）sessions 最近31天内最多128份日志，每3秒最多512KiB，目录发现每30秒一次，检查不重叠。
- 任务开始、完成、中断、压缩事件；气泡底部显示进行中或未确认完成数量。历史完成不通知；完成提醒需用户手动确认，暂不自动识别已读。

## 0.8.24 性能优先的轻量统计（当前行为）

按用户要求取消全历史模式。统计只保留含今日的7个本机自然日，以及约5小时的分钟分组；5小时图为30个10分钟桶，时间边界存在分钟级精度限制。套餐剩余额度查询与Token统计独立，不改变额度的5小时/周窗口。

目录发现每60秒，仅纳入最近7天修改的最多128份日志。单轮每5秒最多128KiB、8个文件；首次每文件只取末尾512KiB（由旧累计量建立基线，不把首次见到的历史累计算作新增）。之后增量跟随，不再补读整份历史。初始历史可缺失，面板注明；显示限量范围完成不代表完整账单。

缓存版本3仅保存轻量结果；旧全历史缓存不会继续补读。过期日/小时/分钟数据逐轮清理。回归覆盖大日志尾读基线、5小时图汇总与缓存恢复。未进行真实机器长时间CPU/GPU负载对照，不承诺固定占用。
