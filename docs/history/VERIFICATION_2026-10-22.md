# 本机验证记录

旧说明曾标注版本为0.9.2；新增用户素材制作流程及最新检查见 `verification-summary.json` 和 `RESOURCE_CHECK.md`。下文保留2026-10-22的历史结果，其18槽位、两套桌宠等描述不是当前版本的功能承诺。

整理日期：2026-10-22。环境：Windows、Windows PowerShell 5.1、Node.js 24、Microsoft Edge。测试依赖由官方 npm registry 安装，并通过 package-lock.json 锁定。

## 公开源码版新增检查

公开目录不再分发运行素材。已验证无素材时的源码检查、C#编译和资源和流程逻辑测试可正常完成；GitHub工作流采用这个模式。外部18个槽位素材的本地导入和SHA-256核对通过，缺少素材、缺少槽位、越界目标及试图在仓库内建立私有素材索引都会明确拒绝。含素材的本地运行包以LOCAL-ONLY命名，不是公开源码发布物。

下方7项完整功能检查记录来自使用本机素材时的同版本程序，不意味着公开克隆后无需素材就能启动界面。Esc实键检查的焦点限制仍然保留，没有记为通过。

## 通过的检查

- 18个素材文件的 SHA-256、素材生成目标与完整性检查。
- 33个 JavaScript 文件语法、40处相对导入和全部JSON解析检查。
- Windows PowerShell 5.1脚本解析与原生C#启动窗口编译。
- 启动顺序、取消、启动失败回退和动态就绪标记。
- 后台/隐藏页面的就绪判定及未布局界面的等待行为。
- 隔离控制中心：仅保留柔光肖像、两套桌宠独立切换、偏好迁移及无页面脚本错误。
- 用户原生消息气泡保持、助手阅读面板及恢复样式。
- 视频原像素播放、末帧循环淡入、延迟就绪后的尺寸过渡和关闭恢复。
- 主窗口重建后的目标切换、后台等待与真实窗口衔接。
- Git忽略规则：账号状态、浏览器配置目录、测试记录、依赖和生成文件不会进入源码提交。
- 干净源码压缩包解压后可独立准备素材、编译和运行源码检查；锁定依赖可重新安装，隔离控制中心检查再次通过。

## 本轮未通过的环境检查

Esc实键自动测试两次因Windows未把焦点交给已验证的测试窗口而中止。输入保护阻止了按键发送；这不是一次成功的Esc功能验证，也未确认存在产品缺陷。`npm test`因此没有整套全绿，不能将本说明解读为“全部检查通过”。

Esc和相关原生代码与之前桌面0.8.9已通过检查的版本相同。本次上传整理改动集中于素材布局、准备工具、元数据、文件清单与说明；没有凭旧结果替代当前实键测试结果。请在可交互的Windows桌面运行完整测试，确保测试窗口可以获得焦点。

## 本次整理修正

1. 删除桌宠元数据中指向缺失`.mcp.json`的注册声明；额度桌宠仍由工坊管理。
2. 将桌宠文件清单改为实际集成文件，去除未随整合版提供的独立安装器引用。
3. 去除桌宠package.json中指向缺失测试目录的脚本；验证统一从仓库根目录执行。
4. 更新启动媒体说明，改为当前用户提供的视频，而不是此前三段拼接的临时动画。
5. 测试依赖改为普通npm安装与锁定文件，不依赖维护者的Codex缓存路径；上传目录不含本机部署脚本和历史清理工具。
6. 素材目录禁止Git自动转换换行，避免Windows克隆后许可文本或语录JSON的字节校验失效。

代码和素材模式扫描未发现待上传的账号数据、常见私钥/令牌或本机绝对路径；模式扫描不保证发现所有可能的敏感信息。CI只检查源码、编译和资源和流程逻辑测试，不替代本机桌面交互测试，也不保证未来桌面应用升级后选择器仍然适配。
